# yaoxiaobai-ai-background-swap

AI 换背景 / 背景替换 Skill —— 把产品图（商品、摆件、人物等）的背景替换为目标背景（浅灰/纯白棚拍台面、纯色底、场景背景、或指定参考背景图），**严格保持主体不变**（数量、形状、颜色、材质、饰物、位置关系）。

已实测单张 / 5 张 / 30 张批量、自动分组等场景。

## 安装

1. 克隆或下载本仓库：
   ```bash
   git clone https://github.com/yaoxiaobai-hub/yaoxiaobai-ai-background-swap.git
   ```
2. 把 `yaoxiaobai-ai-background-swap` 文件夹放入 Agent 工作区的 skill 根目录（如 `workspace/.user_skills/`）。

## 用法

对 Agent 直接说以下任意一句即可触发：

- "把这张图的背景换成浅灰台面 / 纯白底 / 家居场景"
- "把 `D:\某文件夹` 里的图全部换成 XX 背景"
- "按这张图的背景统一一批产品图"
- "这些图先判断是不是同一组商品，分类后按组换背景"
- "给这批玻璃摆件生成几个 Etsy 居家场景背景，我选几个再换背景、最后打包"

### 场景背景工作流（无现成背景时）

1. **生成背景方案**：按平台调性（如 Etsy 居家、ins、北欧、极简、宜家）用文生图生成 4~6 张**空场景背景**（台面留空、无摆件，比例与产品图一致）。
2. **对话筛选**：拼带编号总览图给你挑选，按你的约束过滤（如"摆件放桌面/台面上"→排除置物架/格柜；"背景干净"→无装饰摆件）。
3. **背景替换**：产品图 + 选中背景图 用图生图替换，保留主体逐项写死。
4. **归档**：每个选中背景建一个文件夹，把背景图与对应结果放进去。
5. **打包**：结果 zip 打包交付；先小样试跑、确认后再全量。

### 批量规则

- **有分类子文件夹**：逐个子文件夹单独成批，结果存回各自子文件夹（不新建、不覆盖原图）。
- **图片平铺未分类**：自动识别分组（文件名规律 + 视觉特征），按组处理，并按组建分类子文件夹输出。
- 结果命名：`<原图名>_<目标背景短名>.png`，与原图并存，绝不覆盖原图。
- 超过 10 张自动分批，每批验证后再继续；单张失败不中断整批。

## 核心能力

- **主体高保真**：保留项逐项写死（数量 + 每个主体的颜色/材质/饰物/姿态），不笼统写"保持不变"。
- **双路径换背景**：纯文字描述目标背景 / 参考背景图驱动，两种都实测有效。
- **场景背景工作流**：背景生成 → 对话筛选 → 替换 → 归档 → 打包，全流程实测（已生成 Etsy 居家 6 方案、选定 3 背景试跑成功）。
- **强制验证**：生成后下载实际图片核对主体数量与背景纯净度（生成接口的文字描述可能数错数量，必须看实际图）。
